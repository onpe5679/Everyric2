# Everyric Chrome 1.6.1

곡 제목을 서버와 확장 사이에서 손실 없이 검증하고, 이미 남아 있는 구형 위키 캐시가 새
매처를 우회하지 못하게 하는 정확성 패치입니다.

- 원본 영상 제목·채널·video ID와 검증된 제목 후보를 서버 매칭에 함께 전달
- raw 제목 조각으로만 찾은 곡은 YouTube oEmbed 정체성으로 다시 확인한 뒤 채택
- 기호·단복수·동명이곡 충돌은 자동 채택 대신 보류하고 수동 검색 후보로 분리
- 수동 검색은 최대 5개 후보와 producer/slug 식별정보를 함께 표시
- 구서버 `found:true`, 불가능한 `found+ambiguous` 응답을 클라이언트에서도 재검증
- 구형 `vocaroRef` 캐시 무효화 및 원본/정리 제목·아티스트·채널 provenance가 맞는
  24시간 이내 캐시만 재사용
- 직접 Miraheze 결과의 `/producer`와 영상 아티스트·채널 교차검증
- 채널이 늦게 갱신되는 YouTube SPA에서도 곡 정체성이 바뀌면 위키 소스를 재조회
- 피드백을 제출 시점 최신 행이 아니라 실제 표시 중인 `sync_id`에 귀속

배포 순서는 새 서버를 먼저 적용한 뒤 Chrome 1.6.1을 배포합니다. 기존 오매칭으로 이미
저장된 싱크·번역 레이어·스냅샷·링크는 코드 배포와 별도로 백업 후 행 단위 격리해야 합니다.
