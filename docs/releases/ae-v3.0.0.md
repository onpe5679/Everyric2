# Everyric Studio 3.0.0

- 구 엔진 선택과 서버 싱크 조회를 제거하고 로컬 adaptive 엔진만 사용합니다.
- CEP에서 런타임 설치, 고정 리비전 모델 다운로드, 상태 검사, 업데이트, 복구를 관리합니다.
- `everyric-local-bridge/v1` NDJSON 브리지로 진행률·분석 깊이·취소·결과를 전달합니다.
- 업데이트는 새 런타임 슬롯을 검증한 뒤 활성화하며 기존 슬롯을 롤백용으로 보존합니다.
- 모델 디렉터리를 별도 NVMe 경로로 지정할 수 있습니다.

현재 검증된 로컬 실행 대상은 Windows x64, NVIDIA GPU, CUDA 12.8이며 최소 VRAM은 6GB,
권장 VRAM은 8GB 이상입니다. CPU 또는 원격 서버 폴백은 제공하지 않습니다.
