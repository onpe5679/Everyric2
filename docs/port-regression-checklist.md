# 스택 이식 — 확장 무회귀 검증 목록

**게이트**: 이 목록을 전부 통과하기 전에는 푸시도 배포도 하지 않는다(사용자 지시 2026-08-03).
감사 수정분(9건 + 스키마 + 버저닝)은 이미 검증됐지만 **이식 완료까지 함께 붙든다.**

## 왜 이 목록이 필요한가

이식은 정렬 **출력의 모양**을 바꾼다. 세그 단위가 원문 글자에서 독음 음절로 가고, 표기가
여러 벌(hangul·kana·romaji) 생기고, 보정층이 라인·세그를 옮긴다. 확장은 그 모양을 전제로
카라오케·발음·멜로디를 그린다. **정렬 정확도가 올라가도 표시가 깨지면 회귀다.**

「완료」의 정의: 로컬 서버에서 **熱異常과 ロキ를 실제로 재생성**했을 때 결과가 벤치 채택
스택과 일치하고, 아래 표시 항목이 전부 정상일 것. 대조 없이 완료라고 말하지 않는다.

---

## A. 읽기 경로 — 표시가 깨지지 않는가

| # | 기능 | 확인할 것 | 이식이 깨뜨릴 수 있는 이유 |
|---|---|---|---|
| A1 | 싱크 조회·표시 | 줄이 뜨고 시간이 맞는다 | 응답 필드 추가(additive)는 안전하나 기존 필드 형태가 바뀌면 파싱이 깨진다 |
| A2 | **음절 카라오케** | 노트에 **사용자가 설정한 표기의 독음**이 들어간다. en 곡은 **원문 영어 음절분리**(`beau-ti-ful`) | 표기를 서버가 생성 시점에 하나만 구우면 사용자가 표기를 바꿀 때 재생성해야 한다 — 전 표기를 함께 실어야 한다 |
| A3 | **발음 레인·표기 전환** | hangul·romaji·kana(·en 음절) 전환이 **재생성 없이** 즉시 되고 각 표기의 음절 타이밍이 맞는다 | 표기별 음절 **수가 다르다**(한글 글자 수 ≠ 가나 모라 수). 인덱스를 서로 대응시키면 깨진다 |
| A4 | **멜로디 피아노롤** | 노트가 뜨고 음이름·f0 곡선이 맞는다 | FCPE 노트는 **세그에 붙는다**. 세그 단위가 바뀌면 부착이 어긋난다(`word.notes` vs `line.notes`) |
| A5 | 번역 표시 | 언어 칩·전환·`translations_by_lang` 선채움 | 라인 분할이 바뀌면 번역 인덱스 대응이 어긋난다 |
| A6 | 디버그 레이어 | `active_ratio`·`clamped`·`fixes`·`heard`·`referee` | 보정층 장치 이름이 `fixes[]`에 실려야 한다(신규) |
| A7 | **추임새 띠** | 표시되는가(신규 필드) | 구버전 확장은 무시 → 호환 OK, 새 확장에서만 표시 |
| A8 | 곡 정보 | tempo·key·quality_score·attribution | `quality_score` 의미가 스택마다 스케일이 다르다 — 확장의 절대 임계 `<0.001` 판정이 새 스택에서도 타당한지 확인 |

### A2·A3 보강 — 표기 × 문자계열 매트릭스

표기 파생은 **곡 단위가 아니라 문자 계열 단위**로 성립해야 한다. 한 라인 안에서 계열이
바뀌면 그 지점부터 다른 파생 경로를 탄다.

| 문자 계열 | 파생 표기 | 검증 표본 |
|---|---|---|
| 일본어(가나·한자) | hangul · kana · romaji | 深海少女 · Kikuo(라틴 0%) |
| 라틴(영어) | **en(원문 음절 `beau-ti-ful`)** · hangul · kana · romaji | Madeon · Black Wood |
| 한자(중국어) | hangul · romaji(병음 계열) — 가능한 범위까지 | **BUTCHER VANITY**(en 중간에 zh) |
| **혼재** | 계열별로 갈라 각자 파생 | **numb numb**(라틴 53.7%) |

- 할 수 없는 조합은 **빈 칸으로 두고 명시**한다. 확장은 폴백을 고르면 되지만, 틀린 값이
  들어가면 사용자는 틀린 줄 모른다.
- `ja-mixed` 계열(`_mixed_stage1`·`_mixed_units`·`_mixed_variants`·`_kana_owner_map`)이
  이식에서 유실되면 numb numb 같은 곡은 **가사 절반이 `n|u|m|b`처럼 글자 단위로 쪼개진다.**
- 한자는 가나 정규식에 안 걸린다 — zh를 ja 계열로 새게 하면 안 된다(추임새 레인 선택에서
  실제로 빠졌던 함정).

## 검증 방법

1. **로컬 서버**(`127.0.0.1:8000`)에 새 스택 배선 후 기동.
2. 벤치 14곡 중 대표곡을 유튜브에서 열어 A 항목을 눈으로 확인.
3. **熱異常·ロキ 실제 재생성** → 결과를 벤치 런(`benchmark/runs/bs-polarformer-fp16__*+pp/`)과
   라인·세그 단위로 대조. 일치해야 이식 완료.
4. B·C 항목은 실제 버튼을 눌러 확인. D는 구버전 확장 빌드와 구세대 싱크로.

## 알려진 함정

- **재생성 버튼을 누르면 심어둔 벤치 데이터가 덮인다.** 배선 전에는 누르지 말 것
  (실제로 熱異常이 두 번 덮였다).
- 서버 주소는 `127.0.0.1`로. `localhost`는 Windows에서 요청당 2초 IPv6 스톨.
- 확장이 허용하는 로컬 주소는 `localhost:8000`·`127.0.0.1:8000` **뿐**이다. 다른 포트는
  확장 재빌드가 필요하다.
